01

Estructura de un Script

Todo script en Godot sigue el mismo patrón base. Aquí aprenderás cómo está organizado y cuáles son las funciones especiales que Godot llama automáticamente.

📄

Estructura básica completa

Un script completo con todos sus elementos principales, en el orden correcto.

# 1. Herencia: indica de qué tipo de nodo es este script
extends CharacterBody2D

# 2. Nombre de clase (opcional, permite usar este script como tipo en otros)
class_name Jugador

# 3. Señales propias (se emiten desde este script)
signal vida_cambio(nueva_vida: int)

# 4. Constantes (valores que nunca cambian)
const VELOCIDAD_MAX = 400.0

# 5. Variables exportadas (aparecen en el Inspector de Godot)
@export var velocidad: float = 200.0

# 6. Variables normales del script
var vida: int = 100
var esta_vivo: bool = true

# 7. Referencias a nodos hijos (se asignan cuando el nodo entra a la escena)
@onready var sprite = $Sprite2D
@onready var anim = $AnimationPlayer

# 8. Función _ready: se ejecuta UNA VEZ cuando el nodo entra a la escena
func _ready():
    print("¡Jugador listo!")

# 9. Función _process: se ejecuta CADA FRAME (para lógica visual, UI, etc.)
func _process(delta: float):
    # delta = tiempo en segundos desde el frame anterior (ej: 0.016 a 60fps)
    pass

# 10. _physics_process: igual que _process pero sincronizado con la física
func _physics_process(delta: float):
    move_and_slide()
💡
¿Qué es delta? Es el tiempo en segundos que pasó desde el frame anterior. Al multiplicar la velocidad por delta, el movimiento se ve igual sin importar los FPS del jugador. Por ejemplo: position.x += 200 * delta moverá 200 píxeles por segundo, no 200 por frame.
🔁

Todas las funciones del ciclo de vida

Godot llama estas funciones automáticamente en distintos momentos del juego.

FunciónCuándo se llamaUso típico
_ready()Una vez, al entrar a la escenaInicializar variables, conectar señales
_process(delta)Cada frame (variable)UI, animaciones, lógica no física
_physics_process(delta)Cada tick de física (fijo, 60/s por defecto)Movimiento, colisiones, física
_input(event)Cuando llega cualquier evento de inputCapturar teclas, mouse, gamepad
_unhandled_input(event)Input que ningún nodo anterior procesóInput global (cámara, pausa)
_gui_input(event)Input sobre un nodo ControlBotones e interfaces personalizadas
_draw()Cuando el nodo necesita dibujarseDibujo personalizado (líneas, círculos)
_notification(what)Al recibir una notificación del motorPausa, cambio de visibilidad, foco
_exit_tree()Cuando el nodo sale de la escenaLimpiar recursos, guardar estado

Variables & Tipos de Datos

Las variables son contenedores que guardan información. GDScript 4 tiene tipado estático opcional — lo cual hace tu código más rápido y seguro.

🏷️

Declarar variables

Puedes declarar variables con o sin tipo. Usar tipos es recomendado.

Sin tipo Inferido
var nombre = "Aria"
var nivel = 5
var activo = true
Con tipo Recomendado
var nombre: String = "Aria"
var nivel: int = 5
var activo: bool = true

Constantes y Enums

Las constantes son valores que no cambian nunca. Los enums son conjuntos de constantes con nombre.

# Constante — su valor no puede cambiar
const MAX_VIDA = 100
const GRAVEDAD = 980.0
const NOMBRE_JUEGO = "Mi Aventura"

# Enum sin nombre (constantes globales del script)
enum { NORTE, SUR, ESTE, OESTE }  # NORTE=0, SUR=1, ESTE=2, OESTE=3

# Enum con nombre (requiere prefijo para acceder)
enum Estado { IDLE, CORRIENDO, SALTANDO, ATACANDO, MUERTO }

# Enum con valores personalizados (útil para flags de bits)
enum Capas { SUELO = 1, ENEMIGOS = 2, PROYECTILES = 4, JUGADOR = 8 }

# Usar el enum
var estado_actual: Estado = Estado.IDLE

# Ver todos los nombres/valores del enum
print(Estado.keys())    # ["IDLE", "CORRIENDO", ...]
print(Estado.values())  # [0, 1, 2, 3, 4]
🏷️

Anotaciones de export

Con @export la variable aparece en el Inspector de Godot, permitiendo ajustar valores sin modificar el código.

@export var vida: int = 100                     # Número entero en inspector
@export var nombre: String = "Jugador"          # Texto en inspector
@export var textura: Texture2D                  # Selector de textura
@export var escena_bala: PackedScene             # Selector de escena (.tscn)

# Rango: limita el valor entre mínimo y máximo
@export_range(0, 100) var escudo: int
@export_range(0.1, 10.0, 0.1) var escala: float  # con paso de 0.1

# Enum: muestra un menú desplegable
@export_enum("Fuego", "Agua", "Tierra") var elemento: int

# Archivo y carpeta: selector de ruta
@export_file("*.json") var config_path: String
@export_dir var carpeta_guardado: String

# Texto multilinea: cuadro de texto grande
@export_multiline var descripcion: String

# Color sin canal alpha
@export_color_no_alpha var color_personaje: Color

# Flags (casillas de verificación múltiple)
@export_flags("Volar", "Nadar", "Trepar") var habilidades: int

# Agrupar variables en el Inspector
@export_group("Combate")
@export var dano: int = 10
@export var cadencia: float = 0.5

Conversión de tipos

Cómo transformar un valor de un tipo a otro.

# int ↔ float ↔ String ↔ bool
var n: int    = int("42")       # "42" → 42
var f: float  = float(10)      # 10 → 10.0
var s: String = str(3.14)     # 3.14 → "3.14"
var b: bool   = bool(1)       # 1 → true (0 → false)

# Verificar el tipo de una variable
typeof(n)         # Retorna una constante TYPE_INT, TYPE_FLOAT, etc.
n is int          # true si n es de tipo int
n is Node         # true si n hereda de Node

# Cast seguro (retorna null si falla, no lanza error)
var jugador = nodo as Jugador
if jugador != null:
    jugador.atacar()

Variables especiales

@onready, static y otras formas de declarar variables.

# @onready: asigna el valor cuando _ready() se ejecuta
# Es equivalente a hacer get_node() dentro de _ready()
@onready var sprite   = $Sprite2D
@onready var colision = $CollisionShape2D
@onready var ui_vida  = $UI/BarraVida

# static var: se comparte entre TODAS las instancias de la clase
static var total_enemigos: int = 0

# Variable con setter y getter personalizados
var vida: int = 100:
    set(nuevo_valor):
        vida = clamp(nuevo_valor, 0, 100)  # limitar entre 0 y 100
        vida_cambio.emit(vida)              # emitir señal al cambiar
    get:
        return vida
03

Funciones

Las funciones encapsulan código reutilizable. En GDScript son muy versátiles: soportan tipado, valores por defecto, lambdas y corrutinas.

⚙️

Definir funciones

Todas las formas de declarar una función.

# Función básica sin parámetros ni retorno
func saludar():
    print("¡Hola mundo!")

# Con parámetros tipados
func mover(direccion: Vector2, velocidad: float):
    position += direccion * velocidad

# Con tipo de retorno especificado
func calcular_dano(base: int, critico: bool) -> int:
    if critico:
        return base * 2
    return base

# Con valor por defecto (parámetro opcional)
func crear_efecto(pos: Vector2, escala: float = 1.0, color: Color = Color.WHITE):
    print("Efecto en ", pos)

# Llamadas con valores por defecto
crear_efecto(Vector2.ZERO)               # escala=1.0, color=WHITE
crear_efecto(Vector2.ZERO, 2.0)          # escala=2.0, color=WHITE
crear_efecto(Vector2.ZERO, 1.0, Color.RED)  # todo especificado

# Función estática (no necesita instancia, no tiene acceso a "self")
static func calcular_distancia(a: Vector2, b: Vector2) -> float:
    return a.distance_to(b)
✅
Tip: siempre especifica el tipo de retorno Escribir -> int, -> String, -> void ayuda a Godot a detectar errores antes de ejecutar el juego y hace tu código más fácil de leer.
λ

Funciones Lambda y Callables

Las lambdas son funciones anónimas que puedes guardar en variables o pasar como argumento.

# Lambda básica — función sin nombre guardada en variable
var doble = func(n: int) -> int:
    return n * 2

print(doble.call(5))  # → 10

# Callable: referencia a un método existente
var cb: Callable = saludar   # referencia a func saludar()
cb.call()                    # ejecutar

# bind(): pre-fijar argumentos
func sumar(a:int, b:int) -> int: return a + b

var suma5 = sumar.bind(5)   # "sumar con a=5"
print(suma5.call(3))         # → 8 (5 + 3)

# Muy útil al conectar señales con datos extra
boton.pressed.connect(_al_presionar.bind("boton_inicio"))
⏳

Corrutinas con await

await pausa la función hasta que ocurra algo (una señal, un tiempo, etc.) sin bloquear el resto del juego.

# Esperar N segundos
func aparicion_enemigo():
    print("Enemigo aparecerá en 3 segundos...")
    await get_tree().create_timer(3.0).timeout
    print("¡Enemigo aparece!")
    spawn_enemigo()

# Esperar a que el jugador presione un botón
func esperar_confirmacion():
    print("Presiona el botón para continuar")
    await boton_ok.pressed   # pausa hasta que se presione
    print("Continuando...")

# Esperar el siguiente frame
await get_tree().process_frame

# Esperar el siguiente tick de física
await get_tree().physics_frame

# Esperar a que otra corrutina termine
func secuencia_intro():
    await mostrar_logo()      # espera que esta función termine
    await mostrar_titulo()
    iniciar_juego()
💡
¿Cómo funciona await? Cuando Godot llega a un await, congela esa función y continúa ejecutando el resto del juego normalmente. Cuando la condición se cumple, la función continúa donde se quedó.
04

Control de Flujo

Condicionales, bucles y operadores para dirigir la lógica de tu juego.

🤔

if / elif / else

Ejecuta código solo si se cumple una condición.

# Forma básica
if vida <= 0:
    morir()

# Con else
if tiene_llave:
    abrir_puerta()
else:
    print("Necesitas una llave")

# Con elif (múltiples condiciones)
if vida > 75:
    set_animacion("saludable")
elif vida > 50:
    set_animacion("herido")
elif vida > 25:
    set_animacion("critico")
else:
    morir()

# Expresión ternaria (if en una línea)
# resultado = valor_si_true  if  condicion  else  valor_si_false
var texto = "Vivo" if vida > 0 else "Muerto"
var velocidad = 400.0 if turbo_activo else 200.0
🎯

match (equivalente al switch)

match compara un valor con múltiples patrones. Es más potente que un simple switch.

# Match básico con valores
match estado:
    Estado.IDLE:
        reproducir_idle()
    Estado.CORRIENDO:
        reproducir_correr()
    Estado.SALTANDO:
        reproducir_saltar()
    _:                  # caso por defecto (como el "default:")
        print("Estado desconocido")

# Agrupar varios valores en el mismo caso
match tecla:
    "w", "W", "arriba":
        mover_arriba()
    "s", "S", "abajo":
        mover_abajo()

# Match con captura de variable (bind)
match mensaje:
    ["mover", var x, var y]:
        mover_a(x, y)       # extrae x e y del array
    ["atacar", var obj]:
        atacar(obj)

# Guard: condición adicional dentro del match
match puntos:
    var p when p >= 1000: print("¡Oro!")
    var p when p >= 500:  print("Plata")
    _:                    print("Bronce")
🔄

Bucles: for y while

Para repetir acciones múltiples veces.

# ── FOR ──────────────────────────────────────────────

# range(n): de 0 hasta n-1
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4

# range(inicio, fin): de inicio hasta fin-1
for i in range(3, 8):
    print(i)  # 3, 4, 5, 6, 7

# range(inicio, fin, paso): de 0 a 10 de 2 en 2
for i in range(0, 11, 2):
    print(i)  # 0, 2, 4, 6, 8, 10

# Iterar sobre un array
var enemigos = ["Goblin", "Troll", "Dragón"]
for enemigo in enemigos:
    print("Aparece: ", enemigo)

# Iterar sobre un diccionario (da las claves)
var inventario = {"espada": 1, "pocion": 5}
for item in inventario:
    print(item, ": x", inventario[item])  # "espada: x1", etc.

# ── WHILE ────────────────────────────────────────────

# Ejecuta mientras la condición sea verdadera
var vidas = 3
while vidas > 0:
    jugar_ronda()
    vidas -= 1

# ── CONTROL DE BUCLE ─────────────────────────────────

for n in range(10):
    if n == 5:
        break       # detiene el bucle completamente
    if n % 2 == 0:
        continue    # salta a la siguiente iteración
    print(n)       # solo imprime impares < 5: 1, 3

# pass: no hace nada (placeholder)
func funcion_incompleta():
    pass           # evita error de "cuerpo vacío"

Todo lo que puedes hacer con texto en GDScript — formatear, buscar, dividir, y mucho más.

✏️

Crear y formatear strings

Distintas maneras de construir texto dinámico.

# Comillas simples o dobles
var a = "Hola"
var b = 'Mundo'

# Multilinea (con triple comillas)
var historia = """

var msg = "Jugador: %s · Nivel: %d · Score: %05d" % [nombre, nivel, score]

var velocidad_txt = "Vel: %.1f m/s" % velocidad  # "Vel: 3.5 m/s"

# String.format() con diccionario (más legible)
var texto = "{nombre} ha alcanzado el nivel {nivel}!".format({
    "nombre": "Aria",
    "nivel": 10

Arrays (Listas)

Los arrays guardan colecciones ordenadas de elementos. Se acceden por índice (empezando en 0).

📋

Crear y acceder

Cómo crear arrays y leer/escribir elementos.

# Array vacío
var lista: Array = []

# Array con valores iniciales (puede mezclar tipos)
var items = ["Espada", "Escudo", "Poción"]

# Array tipado (solo puede contener int)
var puntuaciones: Array[int] = [100, 250, 80]

# Acceder por índice (empieza en 0)
print(items[0])   # "Espada"
print(items[2])   # "Poción"
print(items[-1])  # "Poción" (último elemento con índice negativo)
print(items[-2])  # "Escudo" (penúltimo)

# Modificar elemento
items[1] = "Armadura"  # reemplaza "Escudo"

# Tamaño del array
print(items.size())    # 3
print(items.is_empty())  # false

Buscar y organizar

var nums = [3, 1, 4, 1, 5, 9]

# Buscar
nums.has(4)          # true — ¿contiene el valor 4?
4 in nums            # true — otra forma de .has()
nums.find(1)         # 1 — índice de la primera aparición (o -1)
nums.rfind(1)        # 3 — índice de la última aparición
nums.count(1)        # 2 — cuántas veces aparece el valor 1

# Organizar
nums.sort()           # [1, 1, 3, 4, 5, 9] — ordena de menor a mayor
nums.reverse()        # invierte el orden
nums.shuffle()        # mezcla aleatoriamente

# Ordenar con criterio personalizado (por longitud de string)
var nombres = ["Dragón", "Goblin", "Troll"]
nombres.sort_custom(func(a,b): return a.length() < b.length())

# Copiar (sin copiar son referencias al mismo array)
var copia = nums.duplicate()        # copia superficial
var copia2 = nums.duplicate(true)   # copia profunda (para arrays anidados)

# Sub-array
var parte = nums.slice(1, 4)       # elementos del índice 1 al 3
🧪

Funciones de orden superior (map, filter, reduce)

Transformar y filtrar arrays de forma elegante.

var numeros = [1, 2, 3, 4, 5]

# map(): transforma cada elemento
var dobles = numeros.map(func(n): return n * 2)
# → [2, 4, 6, 8, 10]

# filter(): solo conserva los que cumplen la condición
var pares = numeros.filter(func(n): return n % 2 == 0)
# → [2, 4]

# reduce(): acumula todos los elementos en un solo valor
var suma = numeros.reduce(func(acum, n): return acum + n, 0)
# → 15  (0+1+2+3+4+5)

# any(): ¿algún elemento cumple la condición?
var hay_grande = numeros.any(func(n): return n > 4)
# → true (el 5 es > 4)

# all(): ¿TODOS los elementos cumplen la condición?
var todos_positivos = numeros.all(func(n): return n > 0)
# → true
07

Diccionarios

Los diccionarios guardan pares clave → valor. Son ideales para representar objetos con propiedades, configuraciones o bases de datos simples.

📚

Crear y acceder

# Diccionario con datos de personaje
var personaje = {
    "nombre": "Aria",
    "nivel":  10,
    "clase":  "Maga",
    "stats":  {"fuerza": 4, "magia": 18}   # diccionario anidado
}

# Acceder al valor — dos formas:
print(personaje["nombre"])   # "Aria"
print(personaje.nivel)       # 10 (solo funciona con claves que son strings válidas)

# Acceder a diccionario anidado
print(personaje.stats.magia)  # 18

# get(): acceder con valor por defecto (evita errores si la clave no existe)
print(personaje.get("edad", 0))  # 0 (clave "edad" no existe)

# Modificar o agregar clave
personaje["nivel"] = 11          # modifica existente
personaje["oro"] = 500           # agrega nueva clave

# Verificar si existe una clave
if personaje.has("clase"):
    print("Clase: ", personaje.clase)

if "nivel" in personaje:      # otra forma de verificar

Clases & Herencia

GDScript es orientado a objetos. Puedes crear clases, heredar comportamiento y reutilizar código de forma eficiente.

🏛️

extends y class_name

extends define de qué nodo o clase hereda el script. class_name registra la clase para usarla en otros scripts.

# Personaje.gd — clase base
extends CharacterBody2D   # hereda de CharacterBody2D
class_name Personaje       # registra el nombre globalmente

var vida: int = 100
var nombre: String = ""

func _init(p_nombre: String):   # constructor
    nombre = p_nombre

func atacar() -> int:
    print(nombre, " ataca")
    return 10

func recibir_dano(dano: int):
    vida -= dano
    if vida <= 0:
        morir()

func morir():
    print(nombre, " ha muerto")
    queue_free()
🧬

Herencia y super

Un script puede heredar de otro, sobrescribir métodos y llamar al método padre con super.

# Jugador.gd — hereda de Personaje
extends Personaje
class_name Jugador

@export var dano_critico: int = 25

# Sobrescribir el constructor y llamar al padre
func _init(p_nombre: String):
    super._init(p_nombre)   # llama al _init de Personaje
    print("Jugador creado: ", nombre)

# Sobrescribir atacar() para agregar comportamiento extra
func atacar() -> int:
    var dano_base = super.atacar()   # ejecuta el atacar() de Personaje
    if randf() < 0.2:                 # 20% de probabilidad de crítico
        print("¡Golpe crítico!")
        return dano_critico
    return dano_base

# Método exclusivo del Jugador
func usar_habilidad(id: int):
    print("Usando habilidad #", id)

# Verificar herencia
var j = Jugador.new("Aria")
print(j is Jugador)     # true
print(j is Personaje)   # true — también es Personaje por herencia
print(j is Node)        # true — hereda de toda la cadena

Señales (Signals)

Las señales son el sistema de eventos de Godot. Permiten que los nodos se comuniquen sin depender directamente unos de otros — esto hace el código más limpio y flexible.

💡
¿Para qué sirven las señales? Imagina que un botón necesita decirle al juego que fue presionado. Con señales, el botón no necesita saber quién lo escucha — simplemente emite la señal, y cualquier cosa interesada reacciona. Esto evita dependencias directas entre nodos.
📡

Declarar y emitir señales

# Señal sin parámetros
signal jugador_muerto

# Señal con parámetros tipados
signal vida_cambio(nueva_vida: int, max_vida: int)
signal item_recogido(item: String, cantidad: int)
signal posicion_actualizada(pos: Vector2)

# Emitir señal (llamar a todos los conectados)
func recibir_dano(dano: int):
    vida -= dano
    vida_cambio.emit(vida, 100)   # notifica a quien escuche
    if vida <= 0:
        jugador_muerto.emit()
🔗

Conectar señales

Desde código o desde el editor de Godot.

# Conectar desde _ready()
func _ready():
    # Señal del jugador → función de este script
    jugador.vida_cambio.connect(_al_cambiar_vida)
    jugador.jugador_muerto.connect(_al_morir_jugador)

    # Conectar con lambda (función inline)
    boton_pausa.pressed.connect(func():
        get_tree().paused = !get_tree().paused
    )

    # Conectar con bind() — pasa datos extra
    boton_nivel1.pressed.connect(_cargar_nivel.bind("res://nivel1.tscn"))
    boton_nivel2.pressed.connect(_cargar_nivel.bind("res://nivel2.tscn"))

# Funciones receptoras (deben tener los mismos parámetros)
func _al_cambiar_vida(nueva: int, maxima: int):
    barra_vida.value = nueva
    barra_vida.max_value = maxima

func _al_morir_jugador():
    mostrar_pantalla_muerte()

func _cargar_nivel(ruta: String):
    get_tree().change_scene_to_file(ruta)

# Desconectar señal
jugador.vida_cambio.disconnect(_al_cambiar_vida)

# Verificar conexión
jugador.vida_cambio.is_connected(_al_cambiar_vida)  # true/false

_input() y eventos de input

func _input(evento: InputEvent):
    # Evento de teclado
    if evento is InputEventKey:
        if evento.pressed and !evento.echo:  # presionado, no repetido
            if evento.keycode == KEY_ESCAPE:
                pausar_juego()
            if evento.keycode == KEY_F:
                pantalla_completa()

    # Clic de ratón
    if evento is InputEventMouseButton:
        if evento.pressed:
            if evento.button_index == MOUSE_BUTTON_LEFT:
                disparar(evento.position)
            if evento.button_index == MOUSE_BUTTON_WHEEL_UP:
                zoom_in()

    # Movimiento del ratón
    if evento is InputEventMouseMotion:
        var delta_mov = evento.relative  # cuánto se movió
        rotar_camara(delta_mov)

    # Verificar si fue un input action, luego marcar como procesado
    if evento.is_action("saltar"):
        get_viewport().set_input_as_handled()
